# `/web-advice`

Read `~/.claude-wa/skills/web-advice/SKILL.md` and execute it against: <arguments>

**Examples:**
- `/web-advice 8668` — PR review
- `/web-advice docs/pr352-evidence/` — evidence-bundle visual review
- `/web-advice roadmap/design-doc.md` — design-doc review
