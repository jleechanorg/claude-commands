> **For agentic workers:** Use the repository’s existing implementation workflow and keep code changes within the bounded files below. The parent owns review and the Linux pilot; needed old-service restarts remain permitted within current task authority, while browser changes retain the explicit safeguards below. This docs revision performs no runtime or service action.

**Goal:** Add typed session evidence and bounded self-recovery so the Dot Portfolio Coordinator continues authorized work without losing a healthy session or duplicating a send.

**Architecture:** Extend the existing Dot transport with a read-only typed session probe and feasibility-verified bounded message read, then consume it from the coordinator’s current finite observe loop and receipt-safe sender.
