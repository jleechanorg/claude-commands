## Driver scripts produced (lives at `/tmp/`)

These are session-local one-offs, NOT canonical artifacts. Re-derive them
from the SKILL.md recipe next time, or reuse if still on disk:

- `/tmp/batch_export_50plus.py` — main batch driver, inline Firestore calls,
  cross-check fallback (Pitfall #8), idempotent skip via `--fast` flag.
  `--batch-tag` writes frontmatter `ingest_batch:` field for tracking.
- `/tmp/verify_50plus.py` — post-export verification pass. Re-pulls each
  candidate live, compares `len(story_text)` against on-disk raw `.txt`
  size. Logs to `/tmp/verify_50plus_report.jsonl`. Use a 1% drift threshold
  to flag "drift" status; anything <5% is acceptable.
- `/tmp/repair_drift.py` — re-pulls and rewrites only the candidates that
  drifted between batch run and verify run. Uses the same robust
  `get_live_text_robust` helper.
- `/tmp/scan_50plus.py` — single-shot discovery scan. Outputs
  `/tmp/scan_50plus.json` with the full candidate list + entry counts.
- `/tmp/plan_v4.py` — sorts the scan into `to_verify` / `to_ingest_full` /
  `to_ingest_raw_only` buckets. Used by the batch driver.
