# Version-Comparison Template

When brainstorming a new campaign iteration (vN+1), start by mapping every prior version on the same axes. This template was reverse-engineered from Visenya v1→v9 (2026-07-20). For a different recurring character, the columns shift but the structure holds.

## Repeated pillars (the 3 things the user never lets go of)

Across all versions, list the things that survived:

1. **Hidden Apex bloodline** — does the vN+1 keep it? (yes / different lineage but same "hidden unfair" character)
2. **Moral/mortal anchor** — which NPC in vN+1? (Ser Duncan / Daenerys / Davos / Rhaenys / etc.)
3. **Scaling tension mechanic** — does vN+1 have a new one? (Heat System / Ascension Meter / Entropy Toll / Wound Ledger / Reputation Die)

If vN+1 omits any of the 3, the user will *feel* the gap immediately. Each pillar is load-bearing.

## Pivot variables (pick exactly ONE per version)

| Axis | Options that have appeared |
|---|---|
| Setting | Dunk & Egg / HotD Sowing / Rhaegar-wins / House of the Dragon / Slaver's Bay |
| Lineage | House Targaryen proper / House Belaerys / Cadet branch / Bastard of [N] |
| Age | 12 / 14 / 16 ("level-6 sweet spot") |
| Class gestalt | Bard/Mastermind / Ranger-Rogue / Sorcerer / Dragon Scholar |
| Power application | social geometry / physical geometry / dragon-rider |
| Moral anchor | Ser Duncan / Daenerys / Davos / Rhaenys / Old Nan |
| Reputation mechanic | Heat System / Ascension Meter / Reputation Die |
| Endgame cost | Entropy Toll / Wound Ledger / Sovereign Burnout |

The CHA-substitution trick is a meta-axis: which stat is the de facto CHA. v1 used INT/WIS. v9 used DEX/WIS.

## Output format for brainstorm session

Print the comparison table once, then propose:

```
For v(N+1), I recommend pivoting [ONE VARIABLE] from [vN value] to [v(N+1) value]
because [USER-FACING REASON]. The other 7 axes stay.
```

Never propose pivoting two axes in one iteration — the user wants to *feel* the contrast.

## Reference

- Visenya v9 case study (2026-07-20): v9 pivoted power-application from social geometry (v6) to physical geometry. The Blood Dragon reputation mechanic was preserved (Fear-and-Whisper) but upgraded from a linear Heat System 0-100 to a discrete-tier Reputation Die (Unrecognized→Recognized→Feared→Legend).
